## Sobre o projeto

O FlexMotion é um projeto de Internet das Coisas (IoT)
desenvolvido para monitorar movimentos por meio de um
sensor flexível conectado a uma ESP32.

O sistema realiza a leitura dos dados do sensor,
processa os valores obtidos e transmite as informações
para uma plataforma web, permitindo o acompanhamento
dos movimentos em tempo real.

## Objetivos

- Monitorar movimentos utilizando um sensor flexível.
- Realizar a aquisição e o processamento de dados.
- Transmitir informações por meio de MQTT.
- Disponibilizar os dados em uma interface web.
- Desenvolver uma solução integrada de hardware e software.

## Tecnologias utilizadas

- ESP32 DevKit V1
- Sensor Flex
- C++ / Arduino
- HTML, CSS e JavaScript
- MQTT
- HiveMQ Cloud
